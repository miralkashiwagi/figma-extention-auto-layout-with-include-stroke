# Change Auto Layout Settings: Include Stroke
This Figma plugin allows you to change the Auto Layout settings to "Strokes Included" using slash commands or keyboard shortcuts.
(Note: Reverting this setting is not supported.)

このFigmaプラグインは、Auto Layoutの設定を「線を含める」設定に変更する操作をスラッシュコマンドやキーボードショートカットで変更できるようにするためのものです。
